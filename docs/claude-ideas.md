# Claude API 로 더 해 볼 만한 기능

✅ = 이미 들어간 기능. 괄호 안은 주로 쓰는 Claude API 기능입니다.

## 고르기 · 추천

| # | 기능 | 설명 |
| --- | --- | --- |
| 1 | ✅ AI 점심 소믈리에 | "비 오는 날 뜨끈한 국물, 1만원 이하" → 주변 식당 3곳과 이유 (구조화 출력) |
| 2 | 팀 투표 중재 | 여럿의 취향·못 먹는 음식·예산을 받아 모두가 받아들일 만한 곳 추천 (구조화 출력) |
| 3 | 날씨 연동 한 줄 | 기상청 단기예보 + Claude: "비 오고 4도, 오늘은 국물 탭부터" 같은 코멘트 |
| 4 | 시간 맞춤 추천 | "1시 회의 전 40분" → 도보 시간 + 리뷰 속 회전율·웨이팅으로 가능한 곳만 |
| 5 | 회식·접대 추천 | 인원·예산·룸 여부로 추천하고 예약 문의 문자 초안까지 작성 |
| 6 | 개인 취향 프로필 | 다녀온 기록과 별점으로 "국물·한식·혼밥 선호" 요약 → 개인화 가중치 |
| 7 | 대화형 챗봇 | 여러 턴으로 조건을 좁혀 가는 점심 상담 (멀티턴 + 도구 사용으로 목록 검색) |

## 식당 정보 품질

| # | 기능 | 설명 |
| --- | --- | --- |
| 8 | ✅ 새 소식 배지 | 블로그 최신 글에서 신규 오픈·이벤트·시즌 메뉴·점심 특선을 근거 날짜와 함께 추출 |
| 9 | 메뉴판 사진 인식 | 직원이 찍은 메뉴판·영수증 사진 → 메뉴·가격 추출해 카드에 반영 (비전) |
| 10 | 폐업·이전 감지 | 최근 글의 "폐업·이전·휴업" 단서로 목록에서 자동 제외·경고 |
| 11 | 가격 변동 추적 | 리뷰 속 가격 언급을 시간순으로 비교해 "최근 1,000원 올랐어요" |
| 12 | 광고 글 비율 | 협찬·체험단 글 비율을 판별해 '광고성 리뷰 많음' 표시 |
| 13 | 장단점 3줄 | 리뷰들을 "좋아요 / 아쉬워요" 로 요약 (웨이팅, 양, 친절, 소음) |
| 14 | 웨이팅 예측 | 리뷰 속 시간대 언급으로 "12:10 전 도착 추천" |
| 15 | 식이 제한 표시 | 비건·할랄·매운맛·알레르기 단서를 메뉴와 리뷰에서 추정 |
| 16 | 웹 검색 보강 | 블로그 글이 적은 새 가게는 Claude 웹 검색 도구로 오픈 소식·영업시간 확인 (web search) |
| 17 | 데이터 점검 에이전트 | 수집 결과의 이상치(좌표·분류 오류, 중복 가게)를 찾아 수정 PR 을 올림 (Managed Agents) |

| 24 | 칼로리·영양 추정 | 메뉴 기반 대략적 칼로리·단백질로 '가벼운 점심' 필터 |

## 비용 팁

- 같은 시스템 프롬프트는 프롬프트 캐싱으로, 밤사이 대량 작업은 Message Batches 로 처리하면 비용이 크게 줄어듭니다.
- 분류·추출처럼 단순한 일은 `CLAUDE_MODEL=claude-haiku-5-5` 로 충분한지 먼저 비교해 보세요.
