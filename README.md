# 점심은 사람을 만든다 · Lunch Makes the Person

지점 주변에서 **걸어서 갈 만한 점심 식당**을 모아 보여 주고, 고르기 어려우면 **오늘 갈 곳을 뽑아 주는** 사이트입니다.

> 사람은 책을 만들고, 점심은 사람을 만든다.

- **STEP 01 전국 지점 책장** — 34개 지점이 책등으로 꽂힌 책장(또는 지도)에서 지점을 뽑으면 황금 북마크 리본이 꽂힘
- **STEP 02 장르 책갈피** — 한식·중식·일식… 분류 + 도보 5/10/15분 + 점심 영업 + 새 소식(신규 오픈·이벤트·시즌 메뉴) 필터
- **STEP 03 오늘의 한 끼 편찬하기** — 표지가 떨린 뒤 3D 페이지가 넘어가며 당첨 식당 공개, 추천 띠지·폭죽·효과음.
  3회 이상 재추첨하면 「변심 반품·교환 불가」 도장이 쾅, 4회차부터는 재추첨 버튼이 세 번 도망감
- **STEP 04 주변 서가** — 지도(도보 반경) + 식당 카드: Claude 가 지은 패러디 책 제목, 사서 한줄평, 블로그 리뷰 수, 점심 영업 여부, 네이버 지도(평점·리뷰) 바로가기
- 사내 메신저 초대 문구 복사, 「여기로 대출하기」 기록(최근 간 곳 빼고 뽑기), 오늘의 팀 공통 추천
- **AI 사서와 대화**: 여러 번 주고받으며 조건(기분 · 남은 시간 · 예산 · 못 먹는 음식)을 좁혀 추천
- **팀 투표방**: 링크 + 닉네임으로 참여 → 각자 먹고 싶은 것 · 못 먹는 것 · 예산 · 도보 한도 → AI 사서가 3곳 중재 → 투표 → 결정 도장
- **날씨 띠지**: 기상청 단기예보(Supabase `env_forecast`)로 비 · 한파 · 폭염이면 국물 · 가까운 곳 · 냉면을 우대해서 뽑기
- **점심시간 맞춤**: 40분 · 1시간 · 1시간 반 안에 다녀올 곳만 (왕복 도보 + 식사 속도 + 웨이팅)
- **메뉴판 사진**: 직원이 찍어 올리면 Claude 가 메뉴 · 가격을 읽어 카드에 표시 (사진은 비공개 저장)
- **식당 카드 신호**: 영업시간 · 브레이크 · 휴무(출처 표시), 폐업 · 이전 의심, 가격 변동(예: 9,000 → 10,000원), 광고성 리뷰 비율, 웨이팅 예측, AI 웹 조사(영업시간 · 매장 식사 여부 · 대표 메뉴 가격 · 네이버 지도 가게 번호)
- **책장 넘기기 화면**: 지점 → 장르 → 편찬(뽑기) → 서가 4장. 고르면 다음 장으로 넘어가고, 휴대폰은 좌우로 밀어 넘기며 아래쪽 독(큰 버튼 · 단계 · ✋ 한손 모드)으로 조작
- **카드 + 상세 팝업**: 카드는 분류 · 상호 · 새 소식 · 블로그 리뷰 수 · 다녀오는 시간 · 최근 리뷰만, 누르면 상세(휴대폰은 아래 시트)
- **상세 실시간 확인**: 영업시간을 모르는 가게는 상세를 열 때 AI 웹 검색으로 영업시간 · 메뉴 · 가격을 찾아 Supabase 에 14일 저장 (하루 `LIVE_LOOKUP_DAILY` 회)
- **새 소식 (무료)**: AI 분석 전에도 블로그 글 제목 · 요약의 낱말(오픈 · 이벤트 · 신메뉴 · 점심 특선 등)로 먼저 표시
- **사내 한줄평 · 별점**: 직원이 가게마다 별 1~5개와 한 줄을 남기고(로그인 없이 닉네임), 서가에 '사내 베스트셀러 TOP 5' · '사내 평점 순' 정렬
- **1인 예산**: 메뉴 가격 기록 · 메뉴판 사진 · AI 가격대 · 웹 조사로 1인 가격을 어림해 카드에 표시하고, 예산(1만 · 1.2만 · 1.5만원)을 넘는 곳은 뺌
- **내 위치로 찾기**: 처음 온 사람은 위치로 가장 가까운 지점을 바로 열고, 위치를 허용해 둔 사람은 다른 지점 1.5km 안에 있으면 그 지점으로 바꿈
- **도보 · 차량 모드**: 도보는 반경 1km 안(5 · 10 · 15분), 차량은 반경 4km 안 「맛집」 검색 결과까지(차로 10 · 15 · 20분, 도로 우회 · 점심시간 속도 · 주차를 넣은 어림)
- **리뷰 출처**: 네이버 블로그 + 네이버 카페 + 다음 검색(티스토리 · 다음 블로그 · 브런치) + 다음 카페, 가게 이야기로 보이는 글만 셈
- **심심풀이**: 머리에 「오늘의 점심 운세」(하루 한 번, 행운의 장르로 바로 편찬)와 「오늘의 밸런스 게임」(동료 투표 비율)
- **PC 한 화면**: 넓은 화면에서는 세로 스크롤 없이 단계마다 한 화면, 카드 목록만 안에서 스크롤
- **배달 · 포장 전문점 제외**: 이름 · 리뷰(AI) · 웹 조사 · Google 로 판단해 목록 · 지도 · 뽑기에서 뺍니다

## 구조

```
┌──────────── GitHub Actions (평일 06:40 KST) ────────────┐
│ pipeline/collect.ts                                     │
│  카카오 로컬 API ── 반경 1km 음식점 목록                    │
│  네이버 검색 API ── 블로그 리뷰 수 · 최신 글 10개            │
│  Google Places ─── (선택) 별점 · 영업시간 · 폐업 여부        │
│  Claude API ────── 최신 글 → 새 소식 배지 · 요약 · 점심 정보 │
│        ↓ public/data/places/{지점코드}.json 커밋            │
└─────────────────────────┬───────────────────────────────┘
                          ↓ 배포
┌──────────── Cloudflare Workers ─────────────────────────┐
│ 정적 화면(React + Leaflet) + 데이터 JSON                  │
│ /api/ask  AI 점심 소믈리에 (Claude)                        │
└─────────────────────────────────────────────────────────┘
```

| 폴더 | 내용 |
| --- | --- |
| `src/` | 화면 (React, Leaflet 지도) |
| `supabase/` | 투표방 · 메뉴판 제보 테이블 (이미 `Cjs0509arts` 프로젝트에 적용됨) |
| `docs/` | Claude API 로 더 해 볼 만한 기능 |
| `worker/` | Cloudflare Worker (`/api/config` · `weather` · `chat` · `rooms` · `menu-photo` · `menus`) |
| `pipeline/` | 데이터 수집 (`collect.ts`), 지점 엑셀 가져오기 (`import-branches.ts`) |
| `shared/` | 화면·워커·수집이 같이 쓰는 타입과 규칙 (분류, 거리, 점심 판정, 배지 만료) |
| `public/data/` | `branches.json` (지점 34곳), `index.json`, `places/*.json` (수집 결과) |

## 시작하기

### 1. API 키 준비

| 이름 | 어디서 | 필수 | 비용 |
| --- | --- | --- | --- |
| `KAKAO_REST_API_KEY` | [Kakao Developers](https://developers.kakao.com) → 앱 만들기 → 앱 키의 **REST API 키** (앱 설정에서 「카카오맵」 사용을 켜야 할 수 있음) | ✅ | 무료 한도 안 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 네이버 클라우드(ncloud.com) → **NAVER API HUB** → 애플리케이션 등록 → 검색(블로그) 추가 → 인증 정보의 Client ID · Client Secret. 예전 developers.naver.com 키도 자동으로 시도함 | 권장 | 무료 한도 안 |
| `ANTHROPIC_API_KEY` | [Claude Console](https://platform.claude.com) → API Keys | 권장 | 아래 '비용' 참고 |
| `SUPABASE_SECRET_KEY` | Supabase `Cjs0509arts` 프로젝트 → Project Settings → API Keys → **Secret keys** 만들기 (`sb_secret_…`) | 투표방 · 메뉴판 · 날씨에 필요 | 무료 한도 안 |
| `GOOGLE_PLACES_API_KEY` | Google Cloud → Places API (New) | 선택 | 영업시간 · 별점은 Enterprise 요금(월 1,000건 무료). 기본값은 지점마다 도보 10분 안 인기 상위 28곳, 하루 45건, 60일마다 갱신이라 무료 한도 안 |

### 2. GitHub 에 등록

저장소 **Settings → Secrets and variables → Actions**

- **Secrets**: 위 키들 + `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`
- **Variables** (선택)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 비용을 줄이려면 `claude-haiku-5-5` |
| `AI_MAX_PLACES_PER_RUN` | `300` | 하루에 Claude 로 분석할 최대 식당 수 |
| `RADIUS_M` | `1000` | 수집 반경 (m) |
| `MAX_PLACES_PER_BRANCH` | `400` | 지점당 최대 식당 수 (가까운 순) |
| `GOOGLE_MAX_PER_BRANCH` | `0` | 지점마다 인기 상위 N곳만 Google 조회 (0 = 끔) |
| `WEB_SEARCH_MAX_PER_RUN` | `20` | 하루에 AI 웹 조사할 최대 식당 수 (0 = 끔) |
| `WEB_MODEL` | `CLAUDE_MODEL` 과 같음 | AI 웹 조사에 쓸 모델 |

### 3. Cloudflare 배포

1. Cloudflare 대시보드 → 오른쪽 위 프로필 → **API Tokens → Create Token → 「Edit Cloudflare Workers」 템플릿**
   - Account Resources: 내 계정 / Zone Resources: 연결할 도메인(있다면)
2. 대시보드 Workers 화면 오른쪽의 **Account ID** 를 복사
3. 두 값을 GitHub Secrets 에 `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` 로 저장
4. `main` 브랜치에 push 하면 `Deploy` 워크플로가 `https://lunch-makes-the-person.cjs0509.workers.dev` 로 배포
5. **Actions → 식당 데이터 수집 → Run workflow** 로 첫 수집 (처음엔 `ai_budget` 을 크게 잡으면 빨리 채워짐)

#### 내 도메인 연결 (lunch.cjs0509.xyz)

배포할 때마다 `wrangler deploy --domain lunch.cjs0509.xyz` 로 붙고, DNS 레코드와 인증서는 Cloudflare 가 자동으로 만듭니다.
`cjs0509.xyz` 존이 같은 Cloudflare 계정에 있고, API 토큰에 그 존의 DNS Write · Zone Read · Workers Routes Write 권한이 있어야 합니다.

다른 주소를 쓰려면 GitHub → Settings → Secrets and variables → Actions → **Variables** 에 `CUSTOM_DOMAIN` (예: `cjs0509.xyz`) 을 넣고 Deploy 를 다시 실행하세요.
workers.dev 주소 `https://lunch-makes-the-person.cjs0509.workers.dev` 로도 늘 접속할 수 있습니다.

#### 사내에서만 보이게

Cloudflare **Zero Trust → Access → Applications** 에서 도메인을 등록하고 회사 이메일 도메인만 허용하면 됩니다 (50명까지 무료).

### 지점 목록 바꾸기

BookGrid 에서 지점 주소 엑셀을 새로 받으면:

```bash
npm run import:branches -- ~/Downloads/BookGrid_지점주소.xlsx
```

`지점 주소 (수불처)` 시트에서 위도·경도가 있는 줄만 `public/data/branches.json` 으로 옮깁니다 (엑셀 원본은 커밋하지 않음).

## 비용

## Supabase

이미 쓰고 계신 `Cjs0509arts` 프로젝트에 `lunch_` 로 시작하는 테이블 3개와 비공개 버킷 하나를 더했습니다 (`supabase/migrations/`). 다른 테이블은 건드리지 않습니다.

| 이름 | 용도 |
| --- | --- |
| `lunch_rooms` | 투표방 (방 코드 · 지점 · 마감 · AI 중재안 · 결정) |
| `lunch_room_members` | 참여자 닉네임 · 취향 · 표 (로그인 없이 브라우저 키) |
| `lunch_menu_reports` | 메뉴판 사진에서 읽은 메뉴 · 가격. 가리려면 `status = 'hidden'` |
| 버킷 `lunch-menus` | 메뉴판 원본 사진 (비공개) |
| `env_forecast` (기존) | 날씨 띠지가 **읽기만** 함 |

세 테이블 모두 RLS 를 켜고 정책을 두지 않아 브라우저에서는 접근할 수 없고, Worker 가 `SUPABASE_SECRET_KEY` 로만 읽고 씁니다.

## 한계와 메모
